# Boss Action RPG (Unity)

로스트아크식 쿼터뷰 3D 보스 중심 액션 RPG입니다. 바닥에 미리 표시되는 공격 범위(선판정 장판)를 피하며 딜을 넣는 전투가 핵심입니다.

> **현재 상태: 개발 초기(셋업 단계)입니다.** 프로젝트와 폴더 구조를 갖췄고, 첫 기능인 우클릭 이동을 만들고 있습니다.

## 개발 환경
- Unity 6000.3.26f1 (URP)
- C#
- New Input System 1.20.0, AI Navigation 2.0.15
- 기준 플랫폼: PC (마우스·키보드)

## 조작 (계획)
| 입력 | 동작 |
|---|---|
| 우클릭 | 이동 |
| 좌클릭 | 기본 공격 |
| Q W E R A S D F | 스킬 8개 |
| 스페이스바 | 마우스 위치로 즉시 회피 |

## 만들 것
- 플레이어 전투: 이동, 기본 공격, 스킬 8개, 즉시 회피, 피격·사망, 그로기 게이지, 카운터 어택
- 타격감: 히트스톱, 카메라 흔들림, 타격 이펙트와 사운드
- 보스 3마리와 장판 패턴
- 최소한의 RPG 요소: 마을, 퀘스트, 상점, 인벤토리, 장비 강화, 위치 저장

## 폴더
| 경로 | 내용 |
|---|---|
| `Assets/Scripts/` | 게임 코드 (Core, Presentation, Runtime, Tests, Editor) |
| `Assets/Scenes/` | 씬 |
| `Assets/Settings/` | URP 설정 |

## 서드파티 에셋
유료·외부 에셋의 원본 파일은 라이선스 때문에 이 저장소에 포함하지 않습니다(`Assets/ThirdParty/`에는 `.meta`만 올립니다). 그래서 저장소만 받아서 열면 일부 그래픽이 비어 있을 수 있습니다.
